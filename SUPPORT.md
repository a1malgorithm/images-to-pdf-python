# Support

Thanks for using Image2PDF GUI. If you need help or want to report a problem, please use the options below.

- Issues: Open a ticket using the templates: ../../issues/new/choose
- Feature requests: Use the Feature Request template: ../../issues/new/choose
- Sponsorship: If this tool saves you time, you can support via Ko‑fi: https://ko-fi.com/ahmedsyntax

Before creating an issue, please include:
- OS and Python version (e.g., Windows 11, Python 3.11)
- Steps to reproduce (what you clicked and what happened)
- Sample image names or a minimal set (if possible)
- Screenshots or error messages

Response time: Best effort within a few business days.
